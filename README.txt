SIF DIGITAL CONNECT PAGE

Included:
- index.html: responsive landing page with all 11 supplied links (Website, WhatsApp, LinkedIn, Facebook, Instagram, TikTok, YouTube, WeChat, LINE, Botim, RedNote).
- logo.jpg: official company logo displayed at the top of the landing page.

FREE HOSTING (GitHub Pages):
1. Sign in/create a free account at https://github.com/
2. Create a new PUBLIC repository named: sif-digital-connect
3. Upload index.html and logo.jpg to the repository root and commit.
4. Open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Choose branch main and folder /(root), then Save.
7. GitHub will publish a URL similar to https://connectwithsif0.github.io/sif-digital-connect/

QR CODE:
After GitHub gives you the final published URL, create the QR code for that exact URL.
Do not print a QR code until the final public URL is confirmed.

LOGO:
The page displays your official company logo (logo.jpg). Make sure logo.jpg remains in the root folder alongside index.html.
